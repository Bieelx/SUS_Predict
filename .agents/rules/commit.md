# Regras de Commit

Sempre que você for gerar uma mensagem de commit automaticamente (seja pelo botão de gerar commit da IDE ou via chat), você **deve** usar o idioma Português do Brasil (pt-BR).

**Diretrizes:**
- O título do commit deve ser conciso, descritivo e no imperativo (ex: "Adiciona rota para registros locais", "Corrige erro de tipagem no frontend").
- O corpo do commit pode conter mais detalhes sobre o *porquê* e o *que* foi alterado, se necessário.
- Nunca gere mensagens em inglês.
